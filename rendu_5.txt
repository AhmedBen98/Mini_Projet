3. DATASET ET FEATURES ENGINEERING
================================================================================

3.1 DESCRIPTION DU DATASET
---------------------------

Dataset : Diabetes Progression (UCI Machine Learning Repository)
Type : Rgression
Target : Mesure quantitative de la progression du diabte aprs un an

3 Versions Gnres :
V1 (Original) : 442 chantillons
V2 (Augmente): 542 chantillons (+100 synthtiques)
V3 (Varie) : 642 chantillons (+200 avec variations)


3.2 FEATURES ORIGINALES (11 colonnes)
--------------------------------------

1. age - ge (normalis)
2. sex - Sexe (binaire)
3. bmi - Body Mass Index
4. bp - Pression artrielle moyenne
5. s1 - tc, cholestrol total
6. s2 - ldl, lipoprotines de basse densit
7. s3 - hdl, lipoprotines de haute densit
8. s4 - tch, cholestrol total / HDL
9. s5 - ltg, triglycrides
10. s6 - glu, glucose sanguin
11. target - Progression du diabte (25 346)


3.3 FEATURES DRIVES (6 colonnes ajoutes)
--------------------------------------------

12. bmi_category
- Catgories : Underweight, Normal, Overweight, Obese
- Bas sur les quartiles de BMI
- Importance : Classification du risque mtabolique

13. bp_category
- Catgories : Normal, Elevated, High
- Bas sur les seuils de pression artrielle
- Importance : Indicateur de risque cardiovasculaire

14. cholesterol_ratio
- Formule : LDL / HDL (s2 / s3)
- Valeur : Ratio continu
- Importance : Facteur de risque cardiovasculaire majeur

15. metabolic_risk
- Formule : Score composite pondr
0.3 BMI_norm + 0.2 BP_norm + 0.2 LDL_norm +
0.2 Triglycerides_norm + 0.1 Glucose_norm
- Valeur : Score entre 0 et 1
- Importance : Vue d'ensemble du risque mtabolique

16. age_group
- Catgories : Young, Middle, Senior
- Bas sur la distribution d'ge
- Importance : Stratification par groupe d'ge

17. diabetes_risk
- Catgories : Low, Medium, High, Very High
- Bas sur les quartiles de la target
- Importance : Classification du niveau de risque


3.4 PREPROCESSING APPLIQU
---------------------------

a) Gestion des valeurs manquantes :
- Imputation par la mdiane pour les features numriques

b) Dtection et suppression des outliers :
- Mthode : IQR (Interquartile Range)
- Critre : valeurs > Q3 + 1.5IQR ou < Q1 - 1.5IQR
- V1: 18 outliers supprims (4.07%)
- V2: 23 outliers supprims (4.24%)
- V3: 25 outliers supprims (3.89%)

c) Encodage des variables catgorielles :
- Label Encoding pour : bmi_category, bp_category, age_group, diabetes_risk

d) Normalisation :
- StandardScaler pour toutes les features numriques
- Moyenne = 0, cart-type = 1

e) Split des donnes :
- Training : 70%
- Validation : 10%
- Test : 20%

4. MODLE DE MACHINE LEARNING
================================================================================

4.1 ALGORITHME SLECTIONN
---------------------------

Modle : GradientBoostingRegressor (Scikit-learn)

Justification du choix :
Excellente performance sur donnes tabulaires
Capture les relations non-linaires
Robuste aux outliers
Gestion automatique des interactions entre features
Interprtabilit via feature importance


4.2 HYPERPARAMTRES UTILISS
-----------------------------

Configuration optimale (params.yaml) :

diabetes:
n_estimators: 100 # Nombre d'arbres
learning_rate: 0.1 # Taux d'apprentissage
max_depth: 3 # Profondeur maximale des arbres
min_samples_split: 2 # chantillons min pour split
min_samples_leaf: 1 # chantillons min par feuille
subsample: 1.0 # Fraction d'chantillons par arbre
random_state: 42 # Reproductibilit


4.3 OPTIMISATION DES HYPERPARAMTRES
-------------------------------------

Outil : Optuna (Bayesian Optimization)
Mtrique optimise : RMSE (Root Mean Squared Error)
Nombre d'essais : 50
Temps d'excution : ~5 minutes

Espace de recherche :
- n_estimators : [50, 200]
- learning_rate : [0.01, 0.3]
- max_depth : [2, 5]
- min_samples_split : [2, 10]
- min_samples_leaf : [1, 5]
- subsample : [0.8, 1.0]
